# 🐍 Python Learning Tracker

A clean, responsive **90-Day Python Learning Tracker** built with **HTML, CSS, and JavaScript**.

The project helps you follow a structured Python curriculum, mark learning tasks as completed, and track your overall progress directly in the browser.

## ✨ Features

- 📅 **90-day Python curriculum** covering beginner to advanced topics
- ✅ **Interactive task checklist** for every learning activity
- 📊 **Overall progress tracking** with percentage and progress bar
- 📈 **Task and day statistics**
- 🔎 **Task filters**
  - All
  - Today
  - This Week
  - Pending
  - Done
- 🧭 **Sidebar navigation** for quickly moving between weeks and days
- 📱 **Responsive design** for desktop, tablet, and mobile
- 🍔 **Mobile sidebar and bottom navigation**
- 💾 **Automatic progress saving** using browser `localStorage`
- 🎨 **Dark developer-style UI**
- ✨ Smooth hover effects and card animations
- 🐍 Python-focused learning roadmap from setup and fundamentals to deployment and advanced topics

## 🛠️ Technologies Used

- **HTML5** — application structure
- **CSS3** — styling, responsive layout, animations
- **JavaScript** — curriculum rendering, filters, progress tracking, navigation, and state management
- **Browser Local Storage** — saves checklist progress locally
- **Google Fonts** — JetBrains Mono and DM Sans

The project is contained in a single HTML file and does not require a backend or database.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/python-learning-tracker.git
```

### 2. Open the project

Go to the project folder:

```bash
cd python-learning-tracker
```

### 3. Run the tracker

Simply open:

```text
python_learning_tracker.html
```

in a modern web browser.

No build process or package installation is required.

## 💾 Progress Storage

Your checklist state is stored in the browser using `localStorage`.

This means:

- Your completed tasks remain saved after refreshing the page.
- Your progress is stored locally on the current browser/device.
- Clearing the browser's site data can remove the saved progress.
- Progress is not stored on a server.

## 🎯 Project Goal

The goal of this project is to make learning Python more organized and motivating by converting a long curriculum into a daily checklist.

Instead of only reading a roadmap, learners can:

1. Follow the day's topics.
2. Complete individual tasks.
3. Mark tasks as done.
4. Monitor their progress.
5. Continue learning day by day.
